# Cursor

1. Abra seu repositório de testes no Cursor.
2. Copie o conteúdo de `integracoes/cursor/.cursor/` deste kit para `.cursor/` na raiz do seu repo. Mescle arquivos existentes; não sobrescreva personalizações.
3. Adapte os campos **Ajuste antes de usar** das skills escolhidas.
4. Confira as skills em **Customize → Skills**. Peça: `Use a skill triage-nightly para analisar <run>. Só leia e devolva o resumo no chat.`

O pacote inclui 8 skills e os arquivos de memória referenciados por elas. Acesso a terminal, GitHub e tickets depende das ferramentas e permissões do seu ambiente.

Instale só uma variante do kit: o Cursor também pode descobrir `.agents/skills/` e `.claude/skills/`. Se você já usa o pacote Claude neste mesmo repo, não precisa adicionar uma segunda cópia com os mesmos nomes. [Documentação oficial de skills](https://cursor.com/docs/skills).
